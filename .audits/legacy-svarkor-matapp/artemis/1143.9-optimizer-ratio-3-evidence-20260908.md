## 1. The delivered optimizer (what it does)

`optimizer.py` extends the POC `plan_menu` (src/planner/menu.py greedy) with gate-C5's
two changes:

1. **HARD RATIO N5 FILTER *before* greedy** — a dish is eligible only if its
   `andel_extrapris >= ratio_threshold` (default 0.5), where `andel_extrapris(recipe,
   offers)` = fraction of the dish's ingredients matched by an **EXTRAPRIS** offer
   (an offer whose reference price strictly exceeds its sale price — the Phase-4
   `is_extraprice` idiom, `regular_price_cents > price_cents`).
2. **3 SUGGESTIONS (3 seeds)** — `plan_menu` returns `n_variants` (default 3) weekly
   `Plan`s, one per seed from a deterministic set (101, 202, 303); the seed varies the
   greedy tie-break so the suggestions are mutually distinct.

No new dependency — the optimizer + harness use only Python stdlib
(`json, random, dataclasses, datetime, sys`); greedy suffices (PHASE0 §R Q1/Q5).
Verified: `grep -rhE '^\s*(import|from) ' *.py` shows only stdlib (imports pasted in
§4).
